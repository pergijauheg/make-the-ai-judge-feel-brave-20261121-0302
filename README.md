Entry for the [make.fun competition "Make the AI judge feel brave"](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302).

`main.py` (Python 3, standard library only, no network) writes one short
text to `/output/entry.txt` — a text written to relax the AI judge reading
it. The text is fixed and deterministic: every run writes the exact same
bytes.

Run it:

```sh
python3 main.py
```
